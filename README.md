# Zichang Wang — static website

This folder is a self-contained copy of the academic homepage. It can be hosted on GitHub Pages without relying on Squarespace.

## Files

- `index.html`: homepage, styling, and abstract toggles
- `assets/headshot.webp`: local headshot
- `files/`: local CV and paper PDFs
- `404.html`: not-found page
- `.nojekyll`: tells GitHub Pages to serve the files directly

All page links open in a new tab. To update text or links, edit `index.html`. To replace a PDF, keep the same filename or update its relative link in `index.html`.
